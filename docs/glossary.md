# Словарь терминов

Словарь фиксирует, как называются сущности КампусБук. Префикс правил — `TRM`.

## TRM-01. Одна сущность — один термин {#trm-01}

**Обязательно.** Для каждой сущности используем термин из таблицы ниже. Синонимы из столбца «Не используем» не пишем даже ради разнообразия: читатель может решить, что речь о разных вещах.

## TRM-02. Добавляем новый термин в словарь {#trm-02}

**Обязательно.** Если в документе появилась новая сущность, термин добавляем в словарь в том же Pull Request.

## TRM-03. Не используем нежелательные слова {#trm-03}

**Обязательно.** Список нежелательных слов приведен в конце страницы. Его же использует `stylecheck`, шаблоны хранятся в файле `scripts/stop_words.txt`.

## Термины сервиса

<!-- stylecheck: off -->

| Термин | Определение | Не используем |
| --- | --- | --- |
| Помещение | Любое место, которое можно забронировать: аудитория, переговорная, место в коворкинге | Комната, локация |
| Аудитория | Учебное помещение с партами и доской | Кабинет, класс |
| Переговорная | Помещение для встреч до 12 человек | Переговорка, митинг-рум |
| Коворкинг | Открытое пространство, где бронируется отдельное место | Опенспейс |
| Корпус | Здание кампуса, например корпус на Кронверкском проспекте | Здание, адрес |
| Бронирование | Запись о том, что помещение занято на интервал | Бронь, резерв, заявка |
| Интервал | Время начала и окончания бронирования | Слот, окно |
| Отметиться | Подтвердить по QR-коду у входа, что вы пришли в помещение | Зачекиниться, check-in |
| Администратор корпуса | Сотрудник, который управляет помещениями корпуса | Админ, модератор |
| ИТМО ID | Единая учетная запись университета для входа в сервис | Логин, аккаунт ИТМО |
| Токен доступа | Строка, которую интеграция передает в заголовке `Authorization` | Ключ, пароль API |
