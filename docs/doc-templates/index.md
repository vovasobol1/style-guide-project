# Шаблоны

Шаблон задает обязательные разделы документа и их порядок. Скопируйте заготовку в новый файл, замените текст в угловых скобках и удалите подсказки.

| Шаблон | Когда использовать |
| --- | --- |
| [Статья справки](help-article.md) | Пользователю нужно выполнить действие в веб-приложении |
| [Справочник метода API](api-method.md) | Нужно описать один метод REST API |
| [Список изменений](release-notes.md) | Вышла новая версия веб-приложения или API |

Если ни один шаблон не подходит, опишите в Pull Request, какой документ вы пишете, и предложите новый шаблон.
